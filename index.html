About

About Riftted Realities

A browser gaming platform, built one game at a time.

What we're building

Riftted Realities is a gaming platform where players can browse games, create accounts and play directly in the browser. Each game is a self-contained file, so games can be added, updated or removed without affecting the rest of the platform.

A game is only shown as playable when its real game files are in place. Everything else is clearly marked as coming soon.
